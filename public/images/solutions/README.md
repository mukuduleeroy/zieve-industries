# Division media — photography pending

The four SVG files in this directory are original code-authored line schematics: elution equipment, chemical vessels, lubricant drums/gears, and consumables/PPE. The earthmoving division reuses the existing hero schematic. They are illustrative placeholders, not Zieve facilities, stock records, technical diagrams or evidence of completed projects. No stock photography was downloaded.

`src/config/solutions-media.ts` maps the five canonical service slugs to individual media configurations and fallbacks. Replace entries with approved local photographs (`kind: 'image'`) with an approval reference, meaningful alt text, truthful short caption and object positions. Photography uses lazy optimised Next Image; SVGs remain small unoptimised vectors. Only the selected division's media mounts. All panel text participates in an overlapping sizing grid to reserve the maximum text height across selections; media proportions and a caption allowance remain constant.

A failed photo falls back to that division's own schematic. A missing schematic produces a named static placeholder without collapsing the frame. The active panel is never described as company inventory or facilities unless an approved asset/caption establishes that provenance.
